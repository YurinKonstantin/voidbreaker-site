Privacy policy

Void Breaker (Microsoft Store product ID 9MZBX6XLS8N0) · Effective date: 1 November 2026 · Last updated: 1 November 2026

Short version: Void Breaker works fully offline and does not collect, transmit or sell any data. The only data the game writes is your own settings and high scores, stored locally on your PC. This website is a static page without analytics, cookies or third-party resources.

1. Who is responsible

The game Void Breaker and this website are made and maintained by Yurin Konstantin (the “developer”). Contact: the public issue tracker of this site at github.com/YurinKonstantin/voidbreaker-site/issues.

2. What the game does not do

  • The game does not require a network connection to run and does not make network requests.
  • The game does not create accounts, ask for a name, email address or any other personal data.
  • The game contains no telemetry, crash reporting, advertising, in-app purchases or third-party SDKs.
  • The game does not access your files, contacts, camera, microphone or location.

3. What is stored on your device

The game saves only the data needed to keep its own state between launches:

  • settings: music and sound volume, interface language, fullscreen mode, reduced screen shake;
  • the local top-10 high score table and the last score.

These files are kept inside the game’s own data folder, %LOCALAPPDATA%\VoidBreaker. They never leave your device and are not sent anywhere. You can delete them at any time by removing that folder or by uninstalling the game.

4. Purchases and distribution

Void Breaker is distributed through the Microsoft Store and is free. The Store itself is operated by Microsoft, and installing or updating the game through it is covered by the Microsoft Privacy Statement, not by this policy. The developer does not receive personal data from Microsoft about individual players.

5. This website

  • The site is a set of static HTML, CSS and image/video files. There is no backend, no forms and no comments.
  • The site sets no cookies and uses no analytics, advertising or tracking scripts.
  • The site loads no external resources: no CDNs, no web fonts, no embedded third-party players. Fonts are the ones already installed on your system; icons are inline SVG; the trailer is served from this site.
  • The site does not use browser storage (local storage, session storage) and does not fingerprint visitors.
  • The “Microsoft Store” button is a plain link: nothing is sent until you click it and the Microsoft page opens.

6. Hosting

This site is hosted on GitHub Pages, a service of GitHub, Inc. Like any web server, GitHub processes technical data about each request — typically the IP address, the requested URL, the referrer and the browser’s user agent — in its server logs for the purpose of delivering the page and protecting the service. This processing is described in the GitHub Privacy Statement. The developer has no access to those logs and receives no statistics built from them.

7. Children

The game and this site collect no data from anyone, including children. No personal information of children is requested or stored.

8. Your rights

Because no personal data is collected, there is nothing for the developer to export, correct or delete on your behalf. The only stored data is the local save described in section 3, which you control yourself on your own device. If you still have a question about privacy, open an issue in the site’s tracker and it will be answered.

9. Changes to this policy

If a future version of the game or this site changes how data is handled, this page will be updated and the “Last updated” date above will change. The current version is always available at this address.

10. Contact

Questions about this policy or about the game: github.com/YurinKonstantin/voidbreaker-site/issues. Responsible person: Yurin Konstantin.
