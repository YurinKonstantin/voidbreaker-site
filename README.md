# Void Breaker — website

Static website for the game **Void Breaker** (Microsoft Store product ID `9MZBX6XLS8N0`).

- `index.html` — English home page
- `ru/index.html` — Russian home page
- `privacy.html` — English privacy policy
- `ru/privacy.html` — Russian privacy policy
- `styles.css` — all styles (system fonts, no external resources)
- `assets/` — screenshots, hero image and the trailer, served from this repository

Published with GitHub Pages at <https://yurinkonstantin.github.io/voidbreaker-site/>.

The site is plain HTML/CSS with no build step. It uses no CDNs, no web fonts, no analytics,
no cookies and no third-party embeds. The game itself is fully offline and does not collect data.

Contact: [Issues](https://github.com/YurinKonstantin/voidbreaker-site/issues).
